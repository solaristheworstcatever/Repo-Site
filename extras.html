Resources/Tools

Level editors

Recommended level editors:

Henry's Leditor

Has a good UI and is easy to use, Its fairly similar to Rained, but not as frequently updated. It is a good editor it's just discontinued so no further updates for stuff like Watcher.

Rained

Has a good UI and is easy to use, the creator is always open to suggestions.

Ogscule Editor

A smoother and better version of Rain World Editor Plus. It is a good editor it's just discontinued so no further updates for stuff like Watcher.

Other level editors:

Community Editor

Combination of the Drought, MSC, Downpour, Official and Substratum editors. Allows to add custom effects easier than other editors do.

Rain World Editor +

Timofey's first custom level editor. While Timofey is making a second one, this one is not recommended to use.

Monsoon Editor

Was made by MACMAN2003 alongside RWE+, but it has been abandoned.

Official Editor

The original editor, released in 2018. It is here for archivial purposes, and its use is discouraged.

Downpour Editor

Released in 2023, It is here for archivial purposes, and its use is discouraged.

Watcher Editor

Released in 2025, It is here for archivial purposes, and its use is discouraged.

Useful resources

Main Wiki

The official Rain World wiki, containing information about all items in the game.

Modding Wiki

A place to share and obtain information about modding Rain World. Feel free to contribute!

Mods Wiki

A place to collect information on content mods for Rain World. Feel free to contribute!

Region Setup Wiki

This is an addon to the modding wiki. It has a lot of region setup guides to help set up your region nice and easy.

Region Lease

A spreadsheet used to help ensure region mods don't conflict with each other.

Region Lease Checker

A visulaized version of the region lease. This helps also check what acronyms are taken and it can suggest you a different acronym.

Recruitment Board

A doc where you can both look up projects, and post your projects that are in need of help.

Base Game Interactive Map

Detailed maps of all base game and MSC regions.

The Watcher Interactive Map

Detailed maps of all The Watcher Regions although currently it is very broken.

Mod Interactive Map

Detailed maps of several modded regions.

RW Enviromental Noises

This is a playlist of all the Vanilla and Downpour enviromental noises, located in the sounds tab of devs tools.

Tools

Manual Screen Editor

A basic drawing application specializing in modifying/creating rendered screens. It previews+edits depth, level color, shadows, sky, effect color (A,B,batfly)+intensity, pipe connections, indexed colors (baked decals) and grime.

Animation to Rain World Tilesheet aseprite script

An aseprite script for quickly and easily exporting a sprite with multiple frames into a custom Rain World tile graphic. Created to lessen the tedium of creating and testing custom tiles and props by automating the process of converting an aseprite 'animation' to the tilesheet format used by the level editor.

Tile Init Editor

A tool that gives a simple and easy-to-use UI for creating Level Editor tile init lines.

Prop Renderer

A scene and rendering workflow for Blender that slices and converts closed meshes into prop sprite sheets.

Rain World Render Blender Shender

It's the same as the other prop renderer but it's a whole lot more understandable and easier to use.

Drizzle

Faster renderer that comes with, and is used by most level editors.

Camera Angle Visualizer

This helps you see how the camera angles work in a more readable and interactive format.

FloodForge

An in-develpment tool used to manipulate world files and create in-game maps for regions.

World Editor

An older tool used to manipulate world files and create in-game maps for regions.

Cornifer

A tool used to make wiki style maps.

Cornifer Watcher/Modded

A tool used to make wiki style maps. That has been updated for Watcher and Modded.

Room Prompt Generator

Tool for generating random room prompts for when you lack inspiration.

Room Prompt Generator V2

A remake of the original Prompt Generator with a lot more prompts that challenge/inspire you to make rooms.

Budc's Rain World Room Prompt Generator

Similar to the other two prompt generators but it also has more prompts.

Region Name Generator

This is region name generator, it will generate a name for your region.

Region Idea Generator

This is region concept generator. It will generate you a whole region concept.

Andrew Editor

A tools that allows for limited editing of the pre-existing Rain World levels.

Color Picker

This Site tells you specific color codes for over 1000 colors whether it be for dev tools codes or html color codes. Though it has adds and it's very bright.

Autotile Spreadsheet Maker

This is spritesheet maker used to create a tile/prop spreadsheet out of multiple, separate image files rather than manually constructing the sheet yourself. It's planned to be updated further.

Adobe Director

The software used to make the Official, Downpour, and Comms Editors. It can be used to edit the Comms code to add new effects.

Rain World Alphas

This Google Drive link has all three Rain World Aphla's for ease of access and also so you can look at the old rooms.
